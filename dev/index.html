PracticalCAS

A computer algebra system in pure Julia, aimed first at mathematical modelling in ecology and evolution (everything Otto & Day's A Biologist's Guide to Mathematical Modeling needs): exact arithmetic with assumptions, polynomial algebra and factorisation, simplification, equation and system solving, symbolic linear algebra, calculus (limits, series, integration), ODE and recurrence solving, and tools for equilibria and stability, invasion analysis and adaptive dynamics, matrix games and ESSs, structured populations and R₀.

The code is layered (see CLAUDE.md): core → poly → simplify → solve → linalg → calculus → ode → ecoevo, each layer using only the ones before it.
