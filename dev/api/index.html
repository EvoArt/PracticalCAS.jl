PracticalCAS.Cond — Type

PracticalCAS.PhaseData — Type

Numerical data for a phase portrait. states are model coordinates (ternary_data stores all three frequencies); points and vectors are Cartesian drawing coordinates. trajectories contains projected paths from a fixed-step RK4 integration. bounds, labels, and ternary describe the drawing domain. equilibria holds the marked equilibria as (state, point, stability) with stability one of :stable, :unstable or :neutral (from the eigenvalues of a numerical Jacobian; on the simplex, of the two independent frequencies).

source
PracticalCAS.SingularStrategy — Type
SingularStrategy

A singular strategy value with the conditions for evolutionary stability (∂²W/∂m² < 0: no nearby mutant invades) and convergence stability (∂²W/∂m² + ∂²W/∂m∂r < 0: nearby residents evolve towards it), and the resulting type: :CSS (both: an evolutionary end point), :branching (CS but not ES), :garden_of_eden (ES but not CS), :repeller (neither), or :depends.

source
PracticalCAS.Stability — Type
Stability

The local stability of an equilibrium: the point, the Jacobian there, its eigenvalues (when they could be found), the condition for stability (Routh–Hurwitz in continuous time, Jury in discrete time, simplified under the assumptions) and the verdict :stable, :unstable, :depends, or :neutral when the eigenvalues sit on the stability boundary (purely imaginary in continuous time, modulus 1 in discrete time) so that the linearisation does not decide.

PracticalCAS.dsolve — Method
dsolve(rhs, y, t; ic = nothing, t0 = 0)

Solve the first-order equation dy/dt = rhs (in the symbols y and t). Without ic the solution contains the constant C₁; with ic = y₀ it satisfies y(t0) = y₀. Tries, in order: direct integration, linear equations (integrating factor), Bernoulli equations, separable equations. Returns the solution y(t), or a vector when the implicit solution has several branches.

@syms n::positive r::positive K::positive t n₀::positive
dsolve(r*n*(1 - n/K), n, t; ic = n₀)     # K*n₀/(n₀ + (K - n₀)*exp(-r*t))

dsolve(eq, y(t); ic = (t0, [y0, y0′, …]), bc = [y(a) => ya, y(b) => yb])

Solve an equation in the undefined function y (see @funs) and its derivatives D(y(t), t, k): first order as above, linear equations with constant coefficients (after dividing by the leading coefficient), and equations without y itself (reduced in order). bc gives boundary values, as needed for fixation probabilities from a backward equation.

dsolve([rhs₁, rhs₂], [x, y], t; ic = [x₀, y₀])

A linear system with constant coefficients, y' = A y + b, by diagonalisation (see matexp).

PracticalCAS.dynamics_graph — Method
dynamics_graph(model; parameters=Dict(), point=Dict(), selfloops=true, positions=nothing)

Build an influence graph from an ode or recurrence: x → y means that ∂rhs_y/∂x is not identically zero. Signs use symbolic assumptions, optionally after substituting parameters and a state point. An undecidable sign is :unknown; a structural edge that vanishes at point has sign :zero. This is not a compartment-flow or causal graph. For maps the derivative is of the next state, not the increment. Cycles and self-loops are supported. positions may be a dictionary from variables to (x, y).

Draw a symbolic influence graph. Load PracticalBayesPlot to enable drawing. Positive edges are blue, negative vermilion, and unknown grey; edge labels can be :sign, :derivative, or :none. PracticalCAS.extinction_probability — Method
extinction_probability(G, s)

The probability that a branching process with offspring generating function G(s) eventually goes extinct: the smallest root of G(s) = s in [0, 1]. It is 1 when the mean number of offspring G'(1) ≤ 1; otherwise the root below 1. When the comparison of the mean with 1 cannot be decided under the assumptions, the root other than 1 is returned (the answer when the mean exceeds 1). Roots that are known to be outside [0, 1] are discarded.

@syms s p::(0, 1)

PracticalCAS.fixation_probability — Method
fixation_probability(λ, μ, j, i, N)

For a birth–death chain on 0, 1, …, N (absorbing at both ends) that moves from state j up with rate or probability λ and down with μ (terms in the symbol j), the probability of reaching N from i:

Σ_{k=0}^{i-1} Πₗ₌₁ᵏ (μₗ/λₗ)  /  Σ_{k=0}^{N-1} Πₗ₌₁ᵏ (μₗ/λₗ).

N and i may be symbolic when the ratio μ/λ is a constant or a product of powers. In the Moran model with relative fitness r the ratio is 1/r:

@syms j::natural i::natural N::natural r::positive
fixation_probability(r * j * (N - j), j * (N - j), j, i, N)   # (1 - r^-i)/(1 - r^-N)

PracticalCAS.gillespie — Method
gillespie(vars, events, ic, T; parameters = Dict(), rng = nothing, maxevents = 10^6) -> (t, u)

An exact stochastic simulation (Gillespie's direct method) of a continuous-time Markov chain on counts: events is a vector of rate => change pairs, each rate a term in the variables vars (and parameters), each change a vector of increments. Runs from the state ic until time T, no event is possible, or maxevents. Returns the event times t (starting at 0) and the states u (one row per time). Pass rng (e.g. Random.Xoshiro(1)) for reproducibility.

          parameters = Dict(β => 0.003, γ => 0.1))

PracticalCAS.hopf — Method
hopf(m, point) -> (condition, frequency)

The condition for a Hopf bifurcation at an equilibrium of a continuous-time model: a pair of eigenvalues on the imaginary axis with the others in the left half-plane (for two variables, tr J = 0 with det J > 0; in general the Hurwitz determinant Δₙ₋₁ = 0 with the lower ones and aₙ positive), and the angular frequency ω of the oscillations born there (√det J for two variables; nothing above three). For a discrete-time model with two variables, the Neimark–Sacker condition det J = 1 with |tr J| < 2.

hopf(m, point, μ) -> Vector

The values of the parameter μ that satisfy the equality part of the condition.

PracticalCAS.integrate — Method
integrate(f, x)
integrate(f, (x, a, b))
integrate(f, x, a, b)

The antiderivative of f with respect to x (without a constant), or the definite integral from a to b (which may be ∞/-∞), computed from the antiderivative as a difference of one-sided limits. If no antiderivative is found the result is the unevaluated ∫(f, x).

Rational functions are integrated completely (logarithms and arctangents, or sums over the roots of an irreducible polynomial as RootOf); elementary integrands by rules and the Risch–Norman heuristic; some non-elementary ones in terms of erf, erfi, Ei, Si and Ci. Every antiderivative returned has been checked by differentiation.

For a definite integral, poles of a rational integrand inside the interval make the result unevaluated, and the jumps of tan in an antiderivative are accounted for when the bounds are numbers.

PracticalCAS.perturb — Method
perturb(eq, x, ε; order = 2) -> Vector{Term}

Regular perturbation: the roots of eq (an equation or an expression equal to zero) in x as power series in the small parameter ε, up to ε^order. The roots at ε = 0 are found first; each simple root x₀ is then corrected order by order (x = x₀ + x₁ε + x₂ε² + …, each xⱼ from a linear equation). Multiple roots at ε = 0 are skipped (they need fractional powers of ε).

@syms x ε

Useful for eigenvalues of weakly coupled systems (perturb the characteristic polynomial) and equilibria under weak selection or rare mutation.

PracticalCAS.rsolve — Method
rsolve(f, n, t; ic = n₀)

Solve the first-order recurrence n(t+1) = f(n) for n(t). The initial value defaults to the symbol n₀ (named after n). Handles:

  • linear maps a n + b (n(t) = n̂ + (n₀ - n̂) aᵗ, or n₀ + b t when a = 1);

  • linear-fractional (Möbius) maps (a n + b)/(c n + d), through x = 1/n after moving a fixed point to zero; this covers the Beverton–Holt model and haploid selection.

    rsolve([f₁, f₂], [x, y], t; ic = [x₀, y₀])

A linear system n(t+1) = A n + b, by diagonalisation (matpow).

PracticalCAS.rsolve — Method
rsolve(eq, n(t); ic = [n(0), n(1), …], bc = [n(a) => va, n(b) => vb])

Solve a recurrence written as an equation in the undefined function n (see @funs) at shifted arguments n(t + k):

  • linear with constant coefficients, of any order, Σ aₖ n(t + k) = g(t) with g a sum of polynomial × geometric terms (characteristic roots, repeated roots giving tʲ rᵗ, undetermined coefficients for g);
  • first order and linear with coefficients depending on t, n(t + 1) = a(t) n(t) + b(t) (through product and summation);
  • first order and nonlinear, as rsolve(f, n, t).

ic gives the values at t = 0, 1, …, order - 1; bc gives values at any points (boundary values, as for fixation probabilities). Without them the solution has constants C₁, C₂, ….

@syms i::natural N::natural r::positive
rsolve(x(i + 1) - (1 + r) * x(i) + r * x(i - 1) ~ 0, x(i); bc = [x(0) => 0, x(N) => 1])
# (1 - r^i)/(1 - r^N)

Sample dynamics on the three-frequency simplex. A game must have three strategies. A model may contain two independent frequencies (x₃ = 1-x₁-x₂) or three rates whose sum vanishes on the simplex.
